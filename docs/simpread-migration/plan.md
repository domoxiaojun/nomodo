## 当前事实

Reader 的 Block 采用 text、items: list[str]、rows: list[list[str]]，不足以表达行内样式和嵌套结构。Markdown 先转换成 HTML，HTML 再经 itertext 展平。段落内链接另外生成 link block，链接的位置和文本关系丢失。Worker 内容选择优先 Markdown，再纯文本/content；存在文本时可能不采用 htmlContent。媒体在规范化阶段附加在末尾，不能据此保证原文图文顺序。

Reader 使用官方 Notion API。参考扩展的旧 Notion 实现依赖历史非官方接口，不适合直接移植。PureRead 在参考仓库为压缩 JavaScript，通过浏览器 content script 使用站点配置及插件；还没有核查完整规则兼容性或取得可维护的对应源码。

## 目标架构

URL → 路由 → 平台 Worker 或独立网页提取器 → 统一文档树 → Markdown / HTML / Notion。

抓取负责获得内容，提取负责识别正文，解析负责保留结构，渲染负责目标格式降级。保留输入格式、来源和结构化警告；不把 LLM 用作默认正文提取器。

## 阶段一：文档模型与格式保真（首先实施）

- [ ] 引入版本化文档模型：行内文本、链接及样式；块级 children；富文本表格单元格；列表起始编号、表头语义、图片说明与稳定媒体引用。
- [ ] 兼容读取既有 Article JSON，检查 pending 存储、LLM 工具契约与输出、content_hash、Notion checkpoint；旧模型可读取，既有导出身份不能因升级自动失效。
- [ ] Markdown 直接从 tokens 构建文档树；HTML 从 DOM 构建同一模型，保留顺序、换行、嵌套及相对地址的来源信息。
- [ ] 根据声明格式和实际字段选择输入；优先有结构的内容，记录回退原因，避免纯文本掩盖 HTML。结构化媒体只在能够可靠关联时原位合并，无法关联时作为附件且不虚构位置。
- [ ] 从文档树统一生成 Markdown 和 HTML；处理转义、代码围栏、列表缩进及图片链接。为不支持的结构制定明确降级策略。
- [ ] 最小验证：固定样例覆盖段落内样式/链接、三级列表、代码、表格、图文混排、相对 URL、旧 Article 读取及旧导出身份兼容。对照预期结构和语义，不仅断言不抛异常。

## 阶段二：Notion 保真与导出可靠性

- [ ] 将行内样式映射为 rich_text annotations/link，递归输出列表和引用，保留表头及表格内容；未知代码语言明确降级。
- [ ] 按官方接口当前限制切分文本、请求和嵌套块；必要时创建父块后追加 children。扩展批次计数，不能继续只统计 table.children。
- [ ] checkpoint 标记对应稳定文档节点/批次；明确版本变化和部分成功时的恢复行为，保留结果未知时不盲目重建页面的机制。
- [ ] 统一媒体上传去重和生命周期；区分 Worker lease 媒体与网页媒体。图片失败保留正文、说明及可用来源链接。
- [ ] 最小验证：检查请求载荷、跨批次嵌套、部分失败、超时结果未知、重复点击和升级后恢复。实施时核对官方 Notion 文档；真实 OAuth/API 验收单独记录。

## 阶段三：通用网页正文提取

- [ ] 新增独立 extractor 接口；平台链接仍优先 Worker，普通文章进入网页提取器。区分“不支持平台”和 Worker 故障，不用通用抓取悄悄掩盖认证/服务故障。
- [ ] 用代表性固定页面比较维护中的正文提取库，选择一个主引擎；站点声明式规则可覆盖主引擎，避免同时维护多个重复管线。
- [ ] 提取标题、作者、发布日期、正文、图片说明和 canonical URL；保留原始 URL。canonical 元数据不能直接作为任意后续抓取指令。
- [ ] 增加真实网络访问防护：DNS 解析及实际连接地址校验、逐跳重定向校验、超时、响应体与解压资源限制。现有 safe_url 只是字符串筛选，不足以保护服务端抓取。
- [ ] 首批覆盖静态新闻、博客和技术文档；登录态、验证码与必须执行 JavaScript 的页面明确提示。仅有真实样例需求时评估隔离浏览器后备。
- [ ] 最小验证：本地固定 HTML 对照正文/噪声/元数据/媒体，再用选定公开 URL 做少量现场验收；记录站点、日期与失败原因。

## 阶段四：扩展规则迁移与必要优化

- [ ] 核查 PureRead、规则和 vendored 组件各自许可证、来源及版本，建立可复现来源清单后再决定直接移植的范围。
- [ ] 盘点规则中的 URL 匹配、CSS selector、排除节点及脚本依赖；优先迁移声明式部分，禁止执行下载规则携带的任意 JavaScript。
- [ ] 每个迁移站点绑定固定 HTML 样例和预期结果；按实际使用量选首批站点，不声称一次兼容全部历史规则。
- [ ] 仅针对观察到的重复抓取/重复媒体上传/重复渲染优化；缓存应区分用户权限、内容版本、解析器版本与凭据上下文，并支持失效。
